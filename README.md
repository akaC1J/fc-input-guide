# FC Input Guide

Статический сайт-шпаргалка по управлению EA Sports FC / FIFA для GitHub Pages.

## Структура

```text
.
├── index.html
├── assets
│   ├── app.js
│   ├── control-parser.js
│   └── styles.css
└── data
    ├── fc26
    │   ├── controls.js
    │   └── skills.js
    └── games.js
```

## Как добавить игру

`data/games.js` содержит только реестр игр. Данные разделов находятся в отдельных
файлах внутри каталога игры и регистрируются в `window.EA_FC_SECTIONS` до загрузки
реестра.

Для новой игры:

1. Создайте файлы разделов, например `data/fc28/skills.js` и `controls.js`.
2. Подключите их в `index.html` перед `data/games.js`.
3. Добавьте метаданные игры в `window.EA_FC_GAMES`.

Минимальная структура игры:

```js
{
  id: "fc26",
  title: "EA Sports FC 26",
  version: "FC 26",
  sections: {
    skills: {
      title: "Финты",
      categories: [
        {
          id: "1-star",
          title: "1 звезда",
          minSkillRating: 1,
          items: [
            {
              title: "Ball Roll",
              input: "RS hold ← / RS hold →",
              note: "Короткое пояснение, если нужно."
            }
          ]
        }
      ]
    },
    controls: {
      title: "Основы управления",
      categories: [
        {
          id: "attack-basic",
          title: "Атака - основы",
          items: [
            {
              title: "Пас",
              input: "tap A"
            }
          ]
        }
      ]
    }
  }
}
```

## Команды финтов

Чтобы добавить финт во вкладку «Эффективные финты», передайте четвертым аргументом
`true` при создании записи:

```js
move("Прокатывание мяча вправо", "RS hold →", null, true)
```

Вкладка появляется автоматически и показывает отмеченные финты из всех категорий
со звездами. Рейтинг исходной категории сохраняется на карточке.

Финты хранятся в компактном поле `input`. Формат описывает Xbox / PC Controller;
`assets/control-parser.js` преобразует строку в визуальные токены:

- `hold LB`, `tap A` - удерживать или нажать кнопку.
- `RS press` - нажать стик.
- `RS flick ↓ ↑ ↑`, `LS hold ↖` - последовательность движений или удержание стика.
- `RS rotate ↓ ← ↑ →` - дуга по заданной стрелками траектории.
- `RS rotate ↓ ← then RS rotate ← ↓ →` - составное движение из двух дуг.
- `+` - действия выполняются одновременно.
- `then` - следующее действие выполняется после предыдущего.
- `/` - полные альтернативные комбинации; они переключаются точками на карточке.
  Альтернативные кнопки тоже записываются полными вариантами, например
  `tap X then tap A / tap B then tap A`.

Пример:

```text
hold LT + RS flick ↑ ← / hold LT + RS flick ↑ →
```

Один и тот же формат `input` используется для финтов и основ управления. Для
обычных стиков доступны `LS` и `RS`, для произвольной подписи — `text ...`,
например `LS + text без направления`. Отрисовка находится в `assets/app.js`.
